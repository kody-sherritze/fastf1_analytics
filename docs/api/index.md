# API Overview

The API reference documents the reusable Python layer behind the project visuals. It complements [Creating New Visuals](../creating-new-visuals/index.md), which explains the workflow and repository structure, and [Case Studies](../case-studies/index.md), which explains individual analytical results.

## Public entry points

The package exposes two convenience helpers at the top level:

```python
from fastf1_analytics import apply_style, load_session
```

Chart builders are imported from their individual modules. This keeps the chart surface explicit as the library grows:

```python
from fastf1_analytics.charts.tyre_strategy import (
    TyreStrategyParams,
    build_tyre_strategy,
)
```
